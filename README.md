
# 🎧 La Cotorrisa – Automatización y Subtítulos con IA

## 💡 Descripción
Proyecto diseñado para automatizar parte del flujo de edición y publicación de contenido.  
Incluye herramientas para generar subtítulos automáticos, crear clips de video y ayudar al editor con tareas repetitivas.

---

## ⚙️ Tecnologías
- Python 3.10+
- FFmpeg
- OpenAI Whisper
- MoviePy
- Argparse / Click

---

## 🚀 Funcionalidades
✅ Transcripción automática de audio/video.  
✅ Generación de subtítulos `.srt`.  
✅ Creación de clips cortos.  
✅ Script CLI para dividir y convertir archivos.  

---

## 🧠 Ejemplo de uso
```bash
python src/subtitles_generator.py episodio.mp3
python src/clips_generator.py episodio.mp4 --clips 3
python src/editor_tool.py episodio.mp4 --split 10
